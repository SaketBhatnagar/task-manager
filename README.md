- Task Manager

A simple task management application where users can create, update, and delete their daily tasks. This project is designed to help users stay organized and improve productivity.

- Features

1. Add new tasks
2. Mark tasks as complete/incomplete
3.Edit or delete tasks
4.Simple and clean user interface

 -Tech Stack

1. Frontend: HTML/CSS/JavaScript 
2.Backend: Node.js 
3.Database: MongoDB

 Getting Started

-Prerequisites

1. Node.js and npm installed
2.Git

Installation
-bash
git clone https://github.com/yourusername/task-manager.git
cd task-manager
npm install
npm start
